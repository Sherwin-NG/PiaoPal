飘伴 PiaoPal — Windows

1. 将整个 ZIP 解压到一个固定文件夹，然后运行 PiaoPal.exe。
   请勿在 ZIP 压缩包预览中直接启动，也不要只复制 exe。
2. 托盘中的 PiaoPal 图标可打开设置、休息/唤醒、找回宠物和退出。
   Windows 可能把托盘图标放在“显示隐藏的图标”中。
3. 首次大小为 1 倍。关闭设置窗口后桌宠继续运行；退出请使用托盘菜单。
4. 更新前退出旧版，将新版本解压到新文件夹再启动。
   设置和相伴记录保存在当前用户的 LocalAppData/PiaoPal 中。

x64 用于 Intel / AMD 电脑；arm64 用于 Windows on ARM 电脑。
推荐 Windows 11；Windows 10 的支持范围请见发布页面。
运行环境已包含在文件夹中，无需另外安装 .NET。

本社区构建尚未提供 Windows Authenticode 发行者签名。
请从 Sherwin-NG/PiaoPal 的 GitHub Releases 获取，并核对 SHA256SUMS.txt。

PiaoPal for Windows

Extract the entire ZIP, then run PiaoPal.exe. Keep all bundled files together.
Open settings or quit from the notification-area tray icon. Closing settings
keeps the companion running. Preferences and progress stay in LocalAppData/PiaoPal.
Use x64 on Intel/AMD PCs and arm64 on Windows on ARM. No separate .NET install
is needed. This community build does not have an Authenticode publisher signature.
