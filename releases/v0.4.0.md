# 飘伴 PiaoPal 0.4.0

这一版修复了 Intel Mac 加载默认伙伴时可能退出、双屏错位时宠物走出可见桌面的问题，也减少了 Windows 桌宠休息时的重复绘制。

## Mac

- **Intel Mac 启动**。默认角色和步态图集现在使用显卡支持的纹理存储方式，解决部分 Intel Mac 在显示宠物前加载失败的问题。
- **多屏跟随**。当两块屏幕上下错开时，宠物会停在实际可见的屏幕上。相邻屏幕的接缝仍可直接走过，跨越桌面空隙时的重新定位不计入步行里程。
- **成就通知**。拔掉最后一块显示器时，待显示的成就会留在队列中。屏幕恢复后，通知按解锁顺序逐条显示，避免了拔屏时弹出通知导致应用退出的问题。

## Windows

- **休息时减少重绘**。宠物的图像和像素位置相同时，窗口会复用上一帧。呼吸、移动、切换伙伴或重新显示窗口时会按需刷新。
- **首次启动语言**。中文系统界面首次启动使用简体中文，其他系统界面使用英语。升级用户继续使用自己保存的语言。

## 下载与校验

| 电脑 | 下载文件 |
| --- | --- |
| Apple Silicon / Intel Mac，macOS 13 及以上 | [PiaoPal-v0.4.0-macOS-universal.dmg](https://github.com/Sherwin-NG/PiaoPal/releases/download/v0.4.0/PiaoPal-v0.4.0-macOS-universal.dmg) |
| Mac，偏好 ZIP 格式 | [PiaoPal-v0.4.0-macOS-universal.zip](https://github.com/Sherwin-NG/PiaoPal/releases/download/v0.4.0/PiaoPal-v0.4.0-macOS-universal.zip) |
| Windows，Intel / AMD x64 | [PiaoPal-v0.4.0-Windows-x64.zip](https://github.com/Sherwin-NG/PiaoPal/releases/download/v0.4.0/PiaoPal-v0.4.0-Windows-x64.zip) |
| Windows on ARM，ARM64 | [PiaoPal-v0.4.0-Windows-arm64.zip](https://github.com/Sherwin-NG/PiaoPal/releases/download/v0.4.0/PiaoPal-v0.4.0-Windows-arm64.zip) |
| 四个安装包的 SHA-256 校验值 | [SHA256SUMS.txt](https://github.com/Sherwin-NG/PiaoPal/releases/download/v0.4.0/SHA256SUMS.txt) |

更新前先从菜单栏或托盘退出旧版。Mac 打开 DMG 后将 PiaoPal 拖入“应用程序”。Windows 将 ZIP 完整解压到新目录，再运行其中的 `PiaoPal.exe`。Windows 推荐使用 Windows 11，Windows 10 的支持范围见[平台说明](https://github.com/Sherwin-NG/PiaoPal/blob/v0.4.0/docs/windows.md)。

下载后，可在文件所在目录核对校验值。Mac 运行 `shasum -a 256 PiaoPal-v0.4.0-macOS-universal.dmg`。Windows PowerShell 运行 `Get-FileHash .\PiaoPal-v0.4.0-Windows-x64.zip -Algorithm SHA256`。使用其他包时替换文件名，将输出与清单中同名文件的值比对。

Mac 包使用 ad-hoc 签名，尚无 Apple Developer ID 签名及公证。Windows 包尚无 Authenticode 发行者签名。许可与素材署名随包附在 `LICENSE` 和 `THIRD_PARTY_NOTICES.md` 中。

## 验证范围

修复提交通过了 macOS 通用构建、Intel macOS 运行回归、Windows x64 和 ARM64 原生测试，以及发布清单检查。两种 Windows 架构各通过 3,332 项核心断言，并验证了桌宠窗口、重启恢复和自包含安装包。Intel macOS 运行器通过虚拟 GPU 验证了默认角色及步态纹理的加载。错位双屏与断开显示器通过模拟布局和显示事件回归，实体 Intel 显卡和物理热插拔仍待实机验收。[修复回归记录](https://github.com/Sherwin-NG/PiaoPal/actions/runs/44205128371)
