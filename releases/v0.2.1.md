# 飘伴 PiaoPal 0.2.1

新增 Windows 原生版本，同时提供 **Intel / AMD x64** 与 **Windows on ARM ARM64** 免安装包。Mac 继续提供 Apple Silicon / Intel 通用包。

## Windows 新增

- 六款内置宠物，透明桌面显示、鼠标跟随、八方向动画、待机和睡眠。
- 通知区域托盘与设置窗口，可修改伙伴、昵称、大小、速度和中英文语言，支持休息/唤醒、找回宠物和手动检查更新。
- 首次大小为 **1 倍**；关闭设置后宠物继续运行，再次启动会打开已有实例的设置。
- 本地保存相伴里程、等级和连续天数，正常退出时保存剩余路程；配置损坏时保留文件并尝试恢复备份。
- 按实际屏幕工作区处理负坐标与显示变化，避免宠物停在桌面空隙；提供仅保存在本机的启动/退出诊断。
- 自包含 .NET 运行环境，无需管理员权限或另外安装运行时。

Windows 当前支持简体中文和 English。Mac 的成就、卡片、六页回顾、激光逗猫、自定义素材目录与登录时启动尚未移植，完整范围见 [Windows 说明](https://github.com/Sherwin-NG/PiaoPal/blob/v0.2.1/docs/windows.md)。

## Mac

保留 v0.2.0 的异常坐标恢复、缩屏后休眠宠物重定位和退出诊断，默认大小仍为 1 倍，已有设置与进度保留。

## 验证与限制

发布流程分别在 x64 与 ARM64 Windows 运行器上检查运动和保存回归、透明窗口渲染、关闭设置后继续运行、正常退出、跨进程重启恢复及自包含产物启动。Mac 执行现有全套回归、双架构编译与包校验。最后必须同时具备四个已校验安装包，才会生成公开发布所用的统一清单。

自动化不替代所有实体显卡、混合 DPI 多屏、系统睡眠/唤醒和长期运行验收。历史偶发自行退出的原因仍未确证，不承诺本版解决所有偶发退出。强制结束或断电仍可能丢失尚未保存的统计；飘飘四帧步态仍有残余滑移。

## 签名与许可

Mac 包采用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证；Windows 包尚未提供 Authenticode 发行者签名。请核对下载来源与 SHA-256，校验和不替代发行者身份签名。
