# 飘伴 PiaoPal 0.0.2

这一版集中改善飘飘的走路、跟随和休息动作，保留银白毛色、灰纹、绿眼与原有角色形象。

## 这一版

- 飘飘新增独立的八方向行走图集，每个方向四帧，改善腿部伸收、脚掌形态和循环衔接。
- 鼠标跟随改为连续位移，加入平滑起步、到达减速和转向稳定处理；急掉头时不再误插入待机。
- 基准移动速度保持 160pt/s，缩短起步等待，跟随更灵活；仍按用户设置的速度倍率运行，并保留大小和角色设置。
- 待机和睡眠保持原姿势，以底部锚定的轻微呼吸维持稳定轮廓。
- 修正斜向主要支撑脚的回推方向和后腿回收，减少原有拖步；原有五款伙伴保留各自的运动配置。
- 增加步态、起停转向、缩放和帧率适配检查，并通过多轮角色风格、四足结构和步态审核。

## 已知限制

飘飘仍采用四帧像素步态，不能保证每只脚持续锁定地面。NE/NW（斜后方向）外侧后腿仍有残余拖步；小尺寸或高速下，步频上限也会使滑移更明显。本版改善主要支撑动作，没有完全消除滑步。

## 下载

| 电脑 | 文件 |
| --- | --- |
| Apple Silicon 或 Intel Mac，macOS 13+ | `PiaoPal-v0.0.2-macOS-universal.dmg` |
| 同上，偏好 ZIP | `PiaoPal-v0.0.2-macOS-universal.zip` |
| 文件完整性校验 | `SHA256SUMS.txt` |

推荐打开 DMG，将 PiaoPal 拖入 Applications；更新时先退出旧版，再替换应用。启动后从菜单栏爪印打开设置，应用不显示 Dock 图标。GitHub 自动提供的 Source code 是源代码，不是安装包。

同一个安装包支持 Apple Silicon 和 Intel。设置和相伴记录保存在本机，更新沿用 PiaoPal 的原有数据目录。

## 首次打开

当前发行包采用 ad-hoc 签名，**未做 Apple Developer ID 签名与公证**。macOS 可能提示无法验证开发者。核对来源后，参考 [Apple 官方说明](https://support.apple.com/102445)在系统设置中查看打开选项，无需关闭系统安全功能。
