# 飘伴 PiaoPal 0.0.1

飘伴 PiaoPal 的首个独立版本，先为 Mac 提供桌面陪伴。

## 这一版

- 独立的 PiaoPal 工程、应用标识、数据目录与更新地址，版本从 0.0.1 开始。
- 以真实猫咪飘飘为原型的插画图标与像素桌宠；保留全部六款内置宠物。
- 鼠标跟随、八方向动作、发呆、抓痒和睡眠；可调整昵称、大小与速度。
- 相伴统计、32 项成就、陪伴卡图片导出、六页回顾、激光逗猫与菜单栏休息。
- 简体中文、繁體中文、English、Français、日本語、Deutsch、Español。

## 下载

| 电脑 | 文件 |
| --- | --- |
| Apple Silicon 或 Intel Mac，macOS 13+ | `PiaoPal-v0.0.1-macOS-universal.dmg` |
| 同上，偏好 ZIP | `PiaoPal-v0.0.1-macOS-universal.zip` |
| 文件完整性校验 | `SHA256SUMS.txt` |

推荐打开 DMG，将 PiaoPal 拖入 Applications。启动后从菜单栏爪印打开设置；应用不显示 Dock 图标。GitHub 自动提供的 Source code 是源代码，不是安装包。

本版只提供 macOS 下载。数据保存在本机，不提供云同步；独立应用不会自动导入早期试制版本的数据。

## 首次打开

当前发行包采用 ad-hoc 签名，**未做 Apple Developer ID 签名与公证**。macOS 可能提示无法验证开发者。核对来源后，参考 [Apple 官方说明](https://support.apple.com/102445)在系统设置中查看打开选项，无需关闭系统安全功能。
