# 飘伴 PiaoPal 0.3.0

这一版修复 macOS 与 Windows 上宠物自行退出的问题，并让已经记下的相伴进度在崩溃后更容易留下来。已有设置与进度继续保留，默认大小仍为 **1 倍**。Windows 继续提供 x64 与 ARM64 免安装包。

## 这一版

- 修复 Mac 上显示刷新在显示器线程碰触 AppKit 或 Metal、窗口尺寸无法安全绘制，以及显卡设备被移除时导致进程退出的问题。显示器布局开始变化或屏幕休眠时先停止绘制，结束后再恢复；遇到无法绘制的帧就暂停渲染，应用继续留在菜单栏。菜单栏进程不再接受系统的自动终止或突然终止，避免在还没保存进度时被收走。
- 修复 Windows 上分层窗口坐标无效，或某一帧绘制失败时直接退出的问题。放不进窗口坐标的位置会被跳过，单帧失败只记录并在稍后重试，桌宠继续运行。
- Mac 每 **60 秒**，以及在屏幕休眠、系统睡眠、失去焦点、关机和正常退出前，把相伴统计原子写入 `~/Library/Application Support/PiaoPal/cat-stats.json`。原来的偏好键仍然保留。强制结束后，已经写入该文件的里程、等级和连续天数可以恢复。
- Windows 约每 **30 秒**，以及在睡眠、锁屏、注销、设置窗口失去焦点和正常退出时，原子保存 `%LOCALAPPDATA%\PiaoPal\state.json`。保存失败会稍后重试，不会因此退出。

## 验证与限制

发布流程分别在 x64 与 ARM64 Windows 运行器上检查运动和保存回归、透明窗口渲染、关闭设置后继续运行、正常退出、跨进程重启恢复及自包含产物启动。Mac 执行现有全套回归、双架构编译与包校验。最后必须同时具备四个已校验安装包，才会生成公开发布所用的统一清单。

本版修复的是已经定位的自行退出路径，不能据此承诺所有历史偶发退出都已消失。自动化不替代所有实体显卡、混合 DPI 多屏、系统睡眠/唤醒和长期运行验收。强制结束或断电仍可能丢失尚未写入的最近一段统计：Mac 最多约 60 秒，Windows 最多约 30 秒。飘飘四帧步态仍有残余滑移。
