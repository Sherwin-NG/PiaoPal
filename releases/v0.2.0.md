# 飘伴 PiaoPal 0.2.0

这一版改善宠物意外消失或卡住的问题，并增加本地启动与退出诊断，帮助区分正常关闭和未完成正常退出的会话。

## 这一版

- 修复异常鼠标坐标导致宠物永久卡在屏幕边缘的问题；忽略无效样本，正常坐标恢复后继续跟随。
- 修复屏幕缩小后休眠或停靠中的宠物留在屏幕外的问题；显示器布局变化时将宠物移回现有屏幕，保留休眠与停靠状态，重定位不会增加里程。
- 在主线程读取显示器布局，屏幕休眠时暂停渲染，唤醒时刷新显示信息；为绘制等待设置超时，并保护异常帧时间与动画索引。
- 增加仅保存在本机的启动、退出请求与正常退出完成日志。上次缺少正常退出记录时会留下诊断提示，不会直接将其判定为崩溃。
- 默认大小继续为 **1 倍**；已有自定义大小、宠物选择和相伴记录继续保留。保留此前正常退出保存里程和边缘运动的修复。

## 验证范围

自动化回归覆盖语言、素材、运动、统计保存、更新器及 22 项生命周期诊断断言，包含异常坐标恢复、休眠/停靠缩屏重定位与不增加里程的检查。发布流程检查 Apple Silicon / Intel 双架构构建、应用签名完整性、DMG 与 ZIP、SHA-256 清单及许可文件。

本次运行修复已在本机验证关闭设置后继续运行、正常退出和再次启动，重启后仍为 1 倍，原有进度保留。真实显示器热插拔、整机睡眠/唤醒、Intel 真机及长期运行尚未完成全面验收。

## 已知限制

历史偶发自行退出的原因尚未确证。本版修复的是已复现的卡住与屏幕外停留路径，不能据此承诺所有偶发退出或多屏消失问题均已解决。非矩形多屏布局仍沿用外接矩形运动边界。

角色美术未调整。飘飘仍采用四帧像素步态，斜后方向外侧后腿有残余拖步，小尺寸或高速下可能更明显。强制结束进程或系统突然断电仍可能丢失尚未保存的统计。

## 下载

| 电脑 | 文件 |
| --- | --- |
| Apple Silicon 或 Intel Mac，macOS 13+ | `PiaoPal-v0.2.0-macOS-universal.dmg` |
| 同上，偏好 ZIP | `PiaoPal-v0.2.0-macOS-universal.zip` |
| 文件完整性校验 | `SHA256SUMS.txt` |

推荐打开 DMG，将 PiaoPal 拖入 Applications；更新时先退出旧版，再替换应用。启动后从菜单栏爪印打开设置，也可以再次打开 PiaoPal 呼出设置；应用不显示 Dock 图标。GitHub 自动提供的 Source code 是源代码，不是安装包。

同一个安装包支持 Apple Silicon 和 Intel。设置和相伴记录保存在本机，更新沿用 PiaoPal 的原有数据目录。

## 签名与公证

当前发行包采用 ad-hoc 签名，**未做 Apple Developer ID 签名与公证**。macOS 可能提示无法验证开发者，请核对下载来源；无需关闭系统安全功能。
