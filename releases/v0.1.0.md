# 飘伴 PiaoPal 0.1.0

这一版统一预览与正式版首次启动的默认大小为 1 倍，并保留已有的里程保存和屏幕边缘行为修复。

## 这一版

- 独立桌面预览与循环状态预览不再自动放大，默认均使用 1 倍大小，与正式版首次启动一致。正式版此前已默认使用 1 倍；更新后继续保留用户已保存的自定义大小。
- 保留正常退出前保存剩余统计的修复，避免 30 秒定时保存间隔内的最近路程及相关经验丢失。
- 保留原有五款伙伴的屏幕边缘修复：按实际位移累计里程，无法继续移动时进入休息，鼠标回到可达位置后恢复跟随。
- 保留统计保存与边界运动回归，覆盖短会话跨进程保存、重复保存、并发里程累积，以及边缘待机和重新跟随。

## 验证范围

现有自动化回归覆盖语言、素材、运动、统计保存和更新器。发行检查包括默认大小、双架构构建、签名完整性和安装包校验。

Intel 真机、所有多屏组合及长时间稳定性尚未完成全面验收。自动化和双架构构建不能替代这些实际环境检查。

## 已知限制

本版没有调整角色美术。飘飘仍采用四帧像素步态，NE/NW（斜后方向）外侧后腿仍有残余拖步；小尺寸或高速下的滑移可能更明显。

退出保存修复适用于正常退出；强制结束进程或系统突然断电仍可能丢失尚未保存的数据。

## 下载

| 电脑 | 文件 |
| --- | --- |
| Apple Silicon 或 Intel Mac，macOS 13+ | `PiaoPal-v0.1.0-macOS-universal.dmg` |
| 同上，偏好 ZIP | `PiaoPal-v0.1.0-macOS-universal.zip` |
| 文件完整性校验 | `SHA256SUMS.txt` |

推荐打开 DMG，将 PiaoPal 拖入 Applications；更新时先退出旧版，再替换应用。启动后从菜单栏爪印打开设置，应用不显示 Dock 图标。GitHub 自动提供的 Source code 是源代码，不是安装包。

同一个安装包支持 Apple Silicon 和 Intel。设置和相伴记录保存在本机，更新沿用 PiaoPal 的原有数据目录。

## 首次打开

当前发行包采用 ad-hoc 签名，**未做 Apple Developer ID 签名与公证**。macOS 可能提示无法验证开发者。核对来源后，参考 [Apple 官方说明](https://support.apple.com/102445)在系统设置中查看打开选项，无需关闭系统安全功能。
