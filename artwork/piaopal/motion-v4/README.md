# 飘飘正方向行走素材与历史审核

PiaoPal v0.0.2 保留本目录中被当前图集继承的 N / E / S / W 源图、实际编辑提示词，以及前轮独立美术和响应审核。当前完整八方向图集由 [motion-v5 清单](../motion-v5/walk-manifest.json) 打包；本目录不再提供旧版图集的独立打包入口。

## 当前版本采用的素材

| 方向 | 相位 0 / 1 / 2 / 3 | 实际提示词 | 共同缩放 |
| --- | --- | --- | --- |
| E | `e-k0.png` / `e-k1-v2.png` / `e-k2.png` / `e-k3-v2.png` | 同名 `prompt-*.txt` | 0.064 |
| N | `n-k0.png` / `n-k1.png` / `n-k0.png` 水平镜像 / `n-k3.png` | `prompt-n-v1.txt` | 0.100 |
| S | `s-k0.png` / `s-k1.png` / `s-k2.png` / `s-k3.png` | `prompt-s-v2.txt` | 0.100 |
| W | E 逐格水平镜像 | 无额外生成 | 0.064 |

E 采用单帧编辑；N、S 的文件分别是当时生成条带中选定的矩形裁切。N 相位 2 镜像相位 0，使承重脚的领先关系对换；另两帧分别提供左右抬脚。头身平移配准、裁切、锚点和共同缩放已经固定在当前清单中，重现不依赖未采用的候选图。

图像使用内建 imagegen 编辑。程序仅做矩形裁切、共同缩放、平移配准与镜像；alpha > 32 只用于当时测量带留白的裁切范围，裁切内 RGBA 保留，不绘腿、不插值造帧、不做阈值去背。角色来源及第三方归属见 [素材来源](../README.md) 和 [第三方说明](../../../THIRD_PARTY_NOTICES.md)。

前轮 NE、SE 源图已被 motion-v5 斜向素材取代。旧图集清单、生成条带、输入参考图、退稿和过程配准文件仅保留在作者本地，不随 v0.0.2 源码发布，也不参与当前构建。没有删除作者本地的历史文件。
